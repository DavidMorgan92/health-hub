# User stories

## Create exercise plans

As a site owner I want to create exercise plans so that they are available for purchase by users.

Acceptance criteria:

- A plan should be structured like a calendar
  - It contains a set of items per day
    - An item is a free-text exercise instruction
  - A day or range of days can be repeated n times or indefinitely
  - A plan may contain links to products in the store that may be helpful to completing the plan

## Update exercise plans

As a site owner I want to update exercise plans so I can justify a subscription model.

## Sell exercise plans

As a site owner I want to sell exercise plans so I can justify the website's existence.

Acceptance criteria:

- I should be able to specify a subscription price in terms of pounds and pence per month

## Create exercise products

As a site owner I want to create exercise products in the store so that they are available for purchase by users.

Acceptance criteria:

- A product should include at least one image
- A product should include a price in pounds and pence

## Subscribe to plans

As a customer I want to subscribe to any number of exercise and nutrition plans so that I can choose which one(s) to actively pursue.

## View active exercise plan

As a customer I want to view my currently active exercise plan so that I can see what I need to do in the coming days.

## View active nutrition plan

As a customer I want to view my currently active nutrition plan so that I can see what I need to do in the coming days.

## Notify about plan update

As a customer I want to be notified when a plan to which I'm subscribed has updated so that I'm not confused by changes to my subscribed plans.
